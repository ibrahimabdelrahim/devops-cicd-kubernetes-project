# CI/CD Pipeline with Docker and Kubernetes

This project demonstrates a simple DevOps workflow for building, containerizing, and deploying a Python Flask application using Jenkins, Docker, and Kubernetes.

## Tools Used
- Jenkins
- Docker
- Kubernetes
- Python Flask
- CI/CD Pipelines
